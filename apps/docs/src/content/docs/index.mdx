## How it works

Mount one handler on your server. It receives subscriptions from the browser and calls your callbacks.

```ts
// server
import { createPush } from 'pushpilot/server';

export const push = createPush({
  vapid: {
    publicKey: process.env.VAPID_PUBLIC_KEY,
    privateKey: process.env.VAPID_PRIVATE_KEY,
    subject: process.env.VAPID_SUBJECT,
  },
});

export const POST = push.handler({
  onSubscribe: ({ subscription }) => save(subscription),
  onUnsubscribe: ({ endpoint }) => remove(endpoint),
});
```

Enable notifications from a button click in the browser.

```ts
// browser
import { createPushClient } from 'pushpilot/client';

const client = createPushClient();
client.start();
button.addEventListener('click', () => void client.enable());
```

Send to the subscriptions you stored, and delete the ones the push service reports as gone.

```ts
const report = await push.send(rows, { title: 'New reply', url: '/inbox' });
```
